= Configure network bridges for virtualization workloads

[role="_abstract"]
You can configure the `br-ex` bridge for virtualization workloads at installation time using the `networking.hostConfig` parameter in `install-config.yaml`.
This approach simplifies deployment by eliminating manual base64-encoding and MachineConfig manifest creation for clusters that require custom network bridge configurations.
